# Quaternius Universal Base Characters

These avatar files come from the free **Universal Base Characters — Standard** pack by Quaternius and are distributed under **CC0 1.0 Universal**.

Original pack: https://quaternius.com/packs/universalbasecharacters.html

The `.glb` files used here are browser-ready conversions of the original Standard-pack full-body male/female glTF models, sourced from the public BeefTV repository. The model geometry remains Quaternius artwork; runtime coloring is applied by this app.

Files:
- `male.glb` — Quaternius Standard male full-body avatar
- `female.glb` — Quaternius Standard female full-body avatar
